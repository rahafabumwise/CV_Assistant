# Evaluation set reviewed v2

30 drafted student-style questions, written before any model outputs were inspected. Not collected from student interviews. Review and approve as a team. Difficulty: 15 easy, 10 medium, 5 hard. IDs 28–30 require refusal because the corpus cannot supply the requested fact.

Compared with v1: replaced IDs 3, 14, 23 and 26 to reduce redundancy and cover Open Oregon preparation, format and evidence-based writing guidance. Updated affected source locators. The other 26 question texts and expected answers are retained. Record this permitted pre-training revision in the report; do not describe the set as unchanged from a prior submission.

Expected answers describe required content, not mandatory wording. For ID 11, any two appropriate verbs from the source list are valid. Longer answers: 1 = all key points and no material error; 0.5 = useful but missing key points; 0 = wrong, unsupported or inappropriate refusal. For refusal IDs, correct means acknowledging the missing information without inventing the requested fact; a sensible referral is helpful but optional. Two graders should score independently and report initial agreement. Overall score percentage = sum of 0/0.5/1 scores divided by 30, times 100. Refusal accuracy = correctly refused items among IDs 28–30 divided by 3, times 100.

Freeze this reviewed set before model evaluation. Keep it out of SFT training and validation, including paraphrases. Domain documents may contain facts needed to answer the tests; that is expected. Do not append this CSV to the continued-pretraining corpus. No training/model evaluation has been performed here.
